# Демо-наборы заявок для панели табличной загрузки

Четыре маленьких набора заявок, подготовленные для загрузки через штатную панель
табличной загрузки (диспетчерская → загрузка данных → CSV/TSV/XLSX). Все адреса
взяты **дословно** из геокод-каталога официальных регионов (`data/dataset/geocoded/`),
типы работ — из каталога типов (`work-type.catalog.ts`), районы — из официальных
анонимизированных датасетов. Даты — 17.08.2026, как в официальных данных; импорт
приводит их к текущему дню. Идентификаторы заявок — синтетические (серия 900xx),
с оригинальными датасетами не пересекаются.

## Наборы

| Файл | Формат | Регион | Заявок | Срочных | Сюжет |
|---|---|---|---|---|---|
| `01-calm-day-east.csv` | CSV, `;`, Windows-1251 (как у организатора) | Восток | 12 | 2 | Обычный день: подключения, замены, пара аварий |
| `02-mkad-outskirts-day.tsv` | TSV, UTF-8 | Юго-восток | 10 | 3 | День за МКАД: Кашира, Домодедово, Ступино + юг Москвы — большие плечи |
| `03-storm-tuesday-south.xlsx` | XLSX | Юго-центр | 12 | 6 | Авральный вторник: половина заявок срочные, узкие окна 1,5–2 ч |
| `04-light-day-east-utf8.csv` | CSV, запятая, UTF-8 BOM | Восток | 7 | 1 | Лёгкий день: минимальный набор для первого знакомства с панелью |

В каждом файле первая строка — `Адрес Офиса` (подсказка депо для импортёра),
затем шапка и строки заявок. Шапка повторяет формат организатора:
`Заявка; Тип заявки BK; Тип заявки HD; Начало; Окончание; Район; Адрес; Подключение; Гигабитное подключение`.

## Как загрузить

1. Войти диспетчером → «Загрузка данных» → вкладка табличной загрузки.
2. Выбрать файл — кодировка и разделитель определяются автоматически
   (поддерживаются CSV/TSV/XLSX, UTF-8 / UTF-16 / Windows-1251).
3. Проверить сопоставление колонок (шапки наборов распознаются автоматически)
   и предпросмотр geocoding — все адреса резолвятся офлайн из каталога.
4. Подтвердить конвертацию и применить пакет как обычную загрузку.

## Как это проверялось

- Собственный валидатор сверяет каждый файл с каталогами: адрес (после
  нормализации) присутствует в геокод-каталоге региона, тип работы существует,
  окна непустые и положительные, ID уникальны во всех наборах, офисная строка
  на месте. Статус: **все четыре набора валидны**.
- Живой прогон через `POST /dispatch/data/tabular/analyze` — скрипт
  `apps/api/scripts/check-tabular-samples.mjs` (входит под диспетчером,
  read-only предпросмотр). Требует контейнер API, собранный после 27.09
  (коммита с табличной загрузкой); на стенде, собранном раньше, маршрут
  отсутствует — пересоберите образ API.
