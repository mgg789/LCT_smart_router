# Офлайн-граф Московского метро

`core/resources/metro/moscow.json` — проверенный статический граф для
Router Core. Он собирается без сетевого доступа из двух локальных снимков:

- `raw/moscow_subway_routes.json.gz` — выгрузка OSM Overpass от
  `2026-09-22T08:15:26Z`, 34 route relations (17 направлений линий);
- `raw/moscow_boundary_nominatim.json.gz` — геометрия Nominatim для
  административной relation OSM `102269` (Москва, включая Новую Москву).

Сырые JSON сохранены в gzip с `mtime=0`, фиксированным OS-маркером и SHA-256
в `manifest.json`. Повторная сборка не обращается к сети и должна давать
побайтно одинаковый `moscow.json`.

Параметры получения зафиксированы в `manifest.json`: Overpass endpoint
`https://overpass-api.de/api/interpreter` и запрос для relations
`route=subway`, `network=Московский метрополитен` в bbox Москвы с рекурсивным
выводом членов; граница получена через
`https://nominatim.openstreetmap.org/lookup?osm_ids=R102269&format=jsonv2&polygon_geojson=1`.

## Сборка и проверка

Из исходных файлов, если они доступны в `/tmp/navix-metro-data`:

```bash
/Users/mike/Projects/LCT/LCT_smart_router/core/.venv/bin/python \
  data/metro/build_moscow.py
```

Если исходный каталог недоступен, конвертер использует уже сохранённые gzip из
`data/metro/raw/`. Параметры `--source-dir`, `--raw-dir`, `--artifact` и
`--manifest` позволяют собрать отдельную копию и сравнить её с артефактом.

Станция — это нормализованная пара «линия + имя»; платформы двух направлений
усредняются. Порядок остановок берётся из route relation OSM, включая роли
`stop_entry_only` и `stop_exit_only`. Общие станции ветки `4А` канонизируются
в line `4`, а её branch-only станции сохраняют canonical line `4A`; `8А`
сохраняется как `8A`. Одинаковые имена линий соединены reviewed
пересадками, кроме пары `Арбатская` (3/4), которая намеренно не считается
прямой пересадкой. Пересадки с различающимися именами перечислены явно в
конвертере (например, `Чистые пруды — Тургеневская — Сретенский бульвар`,
`Лубянка — Кузнецкий мост`, `Таганская — Марксистская`).

Время поездки — инженерная оценка: `ceil(distance × 1.15 / 41 км/ч)`, минимум
60 секунд. Время перехода — оценка пешего пути по 1,4 м/с, минимум 60 секунд;
Router дополнительно применяет фиксированные 240 секунд `transfer_sec`.
Параметры входа в метро, выхода, ожидания и доступа (`180/120/120/1500`)
зафиксированы в ресурсе. Это не расписание и не обещание фактического времени
в пути.

## Лицензия и атрибуция

Исходные геоданные получены из OpenStreetMap через Overpass API и Nominatim.
Данные OpenStreetMap распространяются по Open Database License (ODbL) 1.0;
см. <https://www.openstreetmap.org/copyright> и
<https://opendatacommons.org/licenses/odbl/1-0/>. Снимки сохраняются для
воспроизводимости конкретной сборки; изменения исходных данных требуют новой
даты, manifest SHA-256 и повторной проверки графа.
