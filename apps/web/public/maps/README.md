# Локальная карта трёх официальных регионов

`official-regions.geojson` — улицы, парки и водоёмы OpenStreetMap для востока,
юго-центра и юго-востока, включая Домодедово, Каширу и Ступино. Область запроса:
37.50–38.20 восточной долготы, 54.80–55.81 северной широты. Это подложка для
ориентации, а не источник стоимостей Router и не обещание адресной точности.

Набор содержит 63 180 объектов, около 15.7 МБ несжатого GeoJSON вместо прежних
2.5 МБ демо-квадрата. Геометрия упрощена методом Ramer–Douglas–Peucker с допуском
0.00004 градуса (не более 4.5 м по широте); конечные точки и замкнутые кольца
сохранены. Здания и адресные подписи не включены. Вне области полнота не гарантируется.

Публичные растровые тайлы не скачивались.

`manifest.json` содержит endpoint Overpass, точный запрос, время исходной базы,
SHA-256 исходного ответа и результата, количество объектов и преобразования.
Воспроизведение из сохранённого ответа на этот запрос:

```bash
python apps/web/scripts/prepare-basemap.py path/to/overpass-response.json
```

Приложение не вызывает Overpass: файл входит в локальный кеш оболочки Vite.
Тест проверяет лицензию, хэш, уникальность объектов и наличие дорожной геометрии
рядом с каждой официальной геокодированной точкой трёх регионов.
