# Локальная карта Москвы внутри МКАД и официальных регионов

`official-regions.geojson` — улицы, парки и водоёмы OpenStreetMap для всей Москвы
внутри МКАД и трёх регионов кейса, включая Домодедово, Каширу и Ступино. Три
перекрывающихся области запроса покрывают 37.35–38.20 восточной долготы,
54.80–55.93 северной широты; граница МКАД целиком лежит внутри. Это подложка для
ориентации, а не источник стоимостей Router и не обещание адресной точности.

Набор объединяет старую подложку трёх регионов и западную и северную части МКАД
по OSM id. Геометрия упрощена методом Ramer–Douglas–Peucker с допуском
0.00004 градуса (не более 4.5 м по широте); конечные точки и замкнутые кольца
сохранены. Здания и адресные подписи не включены. Вне области полнота не гарантируется.

Публичные растровые тайлы не скачивались.

`manifest.json` содержит области и параметры запросов Overpass, время исходной
базы, SHA-256 каждого ответа и результата, количество объектов и преобразования.
Воспроизведение из трёх сохранённых ответов в указанном порядке:

```bash
python apps/web/scripts/prepare-basemap.py path/to/official-regions.json path/to/mkad-west.json path/to/mkad-north.json
pnpm exec biome format --write apps/web/public/maps/manifest.json
```

Приложение не вызывает Overpass: файл входит в локальный кеш оболочки Vite.
Тест проверяет лицензию, хэш, уникальность объектов, дорожную геометрию
по сетке внутри МКАД и рядом с официальными геокодированными точками внутри
выгрузки. Адреса Каширы восточнее 38.20 остаются в кадре карты, но уличная
геометрия там в эту выгрузку не входила.
