# Локальная карта демонстрации

`east-demo.geojson` — выбранные геоданные OpenStreetMap, а не нарисованная подложка
и не маршруты Router. Содержит улицы, парки и водоёмы в районе демонстрационных точек.
Область запроса: 37.63–37.82 восточной долготы, 55.68–55.76 северной широты.
Вне этой области полнота подложки не гарантируется; здания и адресные подписи не включены.

[Атрибуция и условия](https://www.openstreetmap.org/copyright).
Публичные растровые тайлы OSM не скачивались.

`manifest.json` содержит endpoint Overpass, время исходной базы, точный запрос,
хэши исходного ответа и производного GeoJSON, количество объектов и преобразования.
Конвертация воспроизводится из сохранённого ответа Overpass:

```powershell
python apps/web/scripts/prepare-basemap.py path/to/overpass-response.json
```

Исходник получен одним ограниченным запросом к VK Maps Overpass. Приложение не
обращается к Overpass: оно использует локальный файл, входящий в кеш оболочки.
