# apps/frontend — диспетчерский фронтенд NAVIX

Новый фронтенд LCT Smart Router по макету Figma `LCT-CORE`. Заменяет `apps/web`
(legacy остаётся нетронутым, включая приложение инженера на `/engineer/`).

## Запуск

```bash
pnpm --filter frontend dev        # http://127.0.0.1:5174
```

`/api` и `/health` проксируются на `http://127.0.0.1:8000` (System Layer), поэтому
`VITE_API_BASE` в локальной разработке остаётся пустым — см. `docs/frontend-api.md` §1.

| Команда | Что делает |
|---|---|
| `pnpm --filter frontend test` | vitest (jsdom + Testing Library) |
| `pnpm --filter frontend typecheck` | `tsc --noEmit`, strict |
| `pnpm --filter frontend build` | typecheck + production-сборка |
| `pnpm --filter frontend test:e2e` | Playwright (поднимает dev-сервер сам) |

## Архитектура — Feature-Sliced Design

```
src/
  app/        провайдеры, роутинг, глобальные стили и токены
  pages/      экраны (login, …)
  widgets/    составные блоки экранов
  features/   пользовательские действия (auth/request-login-code, …)
  entities/   доменные сущности (session, …)
  shared/     api-клиент, UI-кит, утилиты, ассеты
```

Импорты идут только вниз по слоям: `pages → features → entities → shared`.
Каждый слайс наружу отдаёт только свой `index.ts`.

## Данные

Время от API — целые секунды Unix; перевод в локальное время только на рендере.
Ошибки приходят одним конвертом `{error: {code, message, details, requestId}}`;
ветвление — по `code`, не по HTTP-статусу (`src/shared/api/errors.ts`).

## Дизайн-токены

Цвета в `src/app/styles/index.css` сняты пикселями с отрендеренных фреймов макета.
Макет нарисован в 2x — размеры в коде равны фигмовским, делённым на два.

## Шрифты

- **Murs Gothic Wide Dark** — заголовки и лейблы. Файлы лежат в
  `src/shared/assets/fonts/`, единственное начертание объявлено на весь диапазон
  весов, чтобы браузер не синтезировал фальшивый bold. Шрифт коммерческий —
  проверьте лицензию перед публикацией репозитория.
- **Inter** — текст и кнопки, самохост через `@fontsource-variable/inter`
  (не CDN: демо-контур обязан работать офлайн).

## Известные ограничения

- **Логотип** — растр. Присланный `.svg` оказался белым PNG в обёртке `<svg>`,
  поэтому используется тёмный PNG-экспорт из Figma, отрисованный как CSS-маска с
  заливкой `currentColor` — так один файл работает и на светлом фоне, и на тёмном
  рельсе. Настоящий вектор от дизайнера заменит это одним компонентом.
- **Код из письма** — макет рисует 4 ячейки, контракт присылает 6 цифр; сделано 6.
- **Чаты** подключены к `/dispatch/chats*`: список передач, живой поток
  `/dispatch/chats/events`, ответ, завершение передачи и курсор прочтения.
  Поток без реплея, поэтому список ещё и опрашивается — так дыра в соединении
  затягивается сама, а `unreadCount` пересчитывает сервер.
- **AI** подключён к `/api/v1/ai/*`: диалог диспетчера, потоковый ответ, кнопки
  подготовленных операций. Поток читается через `fetch` + `ReadableStream`, а не
  `EventSource`: тот не умеет слать `Authorization`, а токен в URL здесь запрещён
  (docs/frontend-api.md §9.1).
- Геометрия маршрута и прогресс пересчёта контрактом пока не покрыты.
