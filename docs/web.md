## Figma MAIN (первый проход, `feat/web-figma-dashboard-main`)

Главная сейчас рендерит вёрстку макета 1920×1080
(Figma `28:614` / открытый список политик `29:2552`) из `apps/web/src/figma-dashboard/`.
Слоты заполняет тот же `useDashboard` / `DashboardSnapshot`, что и прежний день диспетчера:
инженеры, заявки, алерты, политика, карта `DayMap`, маршрут. Без сессии страница
показывает вход диспетчера. Запуск: `pnpm dev:web` → http://127.0.0.1:5173.

Локальные пути, чтобы посмотреть новый вход:

- диспетчер, код: http://127.0.0.1:5173/
- диспетчер, запасной пароль: та же страница → «Войти паролем»
- инженер: http://127.0.0.1:5173/engineer

На локалке под клетками кода остаётся «Код для локальной отладки». В проде в том же
месте — «Новый код через 1:30» с обратным отсчётом по `expiresAt` (90 секунд).

На этой ветке экрана инженера ещё не было — карточка входа лежит в
`apps/web/src/figma-dashboard/EngineerAuthPage.tsx` и открывается по `/engineer`.
После успешного кода показывается короткое подтверждение сессии, сам план смены
подключится при стыковке ветки приложения инженера.

Интерактив на мокапе: sliding-pill в сайдбаре, поиск инженера разворачивается
из лупы (повторный клик закрывает), правая колонка тостов (Figma `49:5335` /
`49:6790`: система, прогресс, AI, чат, маршрут, алёрт). Алерты всегда сверху.
Карточка живёт до крестика или свайпа вправо (один и тот же уход вправо) и не
сбрасывается сменой вкладки. Двухпальцевый свайп трекпада сворачивает колонку
как колокольчик (на macOS направление инвертировано). После сворачивания новое
уведомление не поднимает старые: оно коротко показывается сверху и само
уходит через несколько секунд. Колокольчик в этот момент открывает весь стек
уже с новой карточкой. Прогресс-бар не прячется по таймеру — висит до 100% и
тогда снимается. Плюс внизу сайдбара
открывает модалку «Загрузить данные». На экране помещается ровно шесть
карточек до нижнего края контента; остальные ждут в очереди и поднимаются снизу.
Колокольчик плавно заезжает/выезжает стек; бейдж = живое число, жёлтый при
алерте, скрыт если стек пуст. Прогресс 0–100 с ETA; на 100% карточка снимается
сама (`updateToast`). Меню аватарки
«Сбросить данные / Выйти»,
панель политик со свитчами «Рассчитать обеды» и «Прогнозировать пробки»
(подпись compact — «Экономичнее», fast — «Быстрее»). Правая колонка только в двух состояниях:
план смены (клик по карточке бригады) или заявка (точка на карте / топик
в нижней ленте). Крестик снимает выделение и возвращает широкую карту.
В левом верхнем углу карты — компактный переключатель региона: закрытая
кнопка растёт под выбранное имя, открытый список без горизонтального скролла.
Нижняя лента маршрута ещё и перетаскивается мышью (пустое место или серый
ползунок). Вкладка «Политики» в сайдбаре открывает сравнение стратегий в том
же визуальном языке, что и MAIN; длинное описание сверху снято, повторный
запуск расчёта — «Пересчитать». Вкладка «Заявки» — таблица Figma REQUESTS
(49:6343): номер, адрес, услуга, окно, инженер, статус; поиск по номеру и
адресу; сортировка «По использованию» / номеру / окну (выбранный пункт —
скруглённая подложка внутри меню). В UI номер — первые
8 символов id. Статусы по Tips 55:7485: назначена, выполнена, без назначения,
в работе, отменена — овальные чипы. Клик по строке открывает страницу заявки
REQUET (55:7636): стрелка назад и тип работ в одной строке над картой
(центры совпадают, заголовок не режется картой). Карта 1194×894 только
с точкой этой заявки. Клик по «Заявка №» копирует короткий номер;
клик по строке адреса / почты / ФИО / окна / инженера — это значение.
В панели «План дня» так же копируются номер и адрес. Писем клиента
в снимке нет — строка пустая. «Написать / переназначить / отменить»
пока без API. Баннер офлайн-карты на плане дня — компактный чип
в правом верхнем углу, чтобы не перекрывать селектор региона.
Вкладка «Алерты» (Figma 49:5629 / карточка 49:5696) — белая карточка
1710×211: заголовок, опционально имя через точку, tip-чип, текст
«Причина: …», жёлтая «К заявке», контурная вторая кнопка, «Разобрать
в AI». Алерты висят, пока план/система их не закроет. Уведомления —
тот же компонент: синий фон, белый текст, иконка вместо tip, одна
кнопка «Скрыть» (тот же размер, тёмный фон и белая обводка).
Внутри каждого блока — по времени прибытия. Если в живом снимке нет
открытых алертов, инбокс и колонка тостов заполняются демо-карточками.
Колонка колокольчика начинается выше, карточки с тенью, под ними
размытие и затемнение, которое слева сходит на нет. «Разобрать все
в AI»: стеклянная белая стрелка (49:5765), если есть алерты; плоский
кружок, если алертов нет. Клик по копируемому полю вспыхивает рамкой
и мигает иконкой copy.
«Разобрать в AI» и смена окна пока без API. Демо-ростер
из 7 инженеров, если живого снимка ещё нет.

## Что на экране (живой контур до замены)

День диспетчера, сравнение политик и реестр инженеров:

- список инженеров, неназначенные заявки, карта MapLibre, таймлайн маршрута.
  Длинные имена (бригада или человек) режутся в конце, чтобы не наезжать на км
- панель заявки и выбранного маршрута: объяснение «Факты → влияние → результат»
  для трёх случаев — почему заявка без назначения, почему назначена именно этой
  бригаде (полное имя, не первое слово), почему маршрут такой. Простой инженер
  при остатке работы тоже получает своё объяснение. Тексты собираются из фактов
  снимка, не из одной заготовленной фразы (`context/11` §3)
- в шапке дня — суммарный пробег видимых бригад выбранного региона
- навыки заявки и инженера видны в списке и карточке; на карте у точки остаётся
  только порядковый номер. Если круги наложились, цифра остаётся у верхнего,
  нижняя скрывается — иначе MapLibre рисует все номера поверх всех кругов.
  Назначение по навыку — жёсткое ограничение солвера
- модалка политик (каталог + выключатель обеда). Обед по умолчанию выключен
  (`lunches_enabled=false`, context/50 §3)
- режим управления в шапке — настоящий переключатель AUTO/MANUAL (`POST /dispatch/mode`)
- селектор региона вверху панели дня; официальным регионам — стабильные различимые
  цвета, загруженным регионам — детерминированный цвет из палитры
- плюс внизу сайдбара MAIN открывает модалку «Загрузить данные»: дроп-зона JSON,
  **«Выбрать из файлов»**, слева жёлтая **«Использовать сет из ТЗ»**, справа «Отмена» и
  жёлтая **«Применить»** после выбора файлов. Импорт ТЗ берёт официальные три
  региона из репозитория; свой JSON проверяется в браузере и применяется атомарно
- семь шагов ТЗ кликами: [tz-acceptance.md](./tz-acceptance.md)
- надписи интерфейса — на русском; панель «Подключено / Проверить связь» с прода
  снята, диагностика больше не висит над планом дня

## Данные

Абсолютные времена — секунды Unix. Живой HTTP идёт через `apps/web/src/api/client.ts`:

| UI | sys |
|---|---|
| Список дня / панель заявки | `GET /api/v1/dispatch/requests` → `RequestView` |
| Колонка инженеров | `GET /api/v1/dispatch/engineers` → `EngineerView` + `EngineerDayView` |
| Карта, таймлайн, причины | `GET /api/v1/dispatch/plan` → `PlanView` |
| Неназначенные / alerts | `GET /api/v1/dispatch/alerts` |
| Подписи политик | `GET /api/v1/dispatch/policies` |
| Выключатель обеда | `GET/PUT /api/v1/dispatch/router/technical-settings` |
| Загрузка пакета региона/заявок | `POST /api/v1/dispatch/data/upload` |

Карта не претендует на текущую позицию инженера: GPS-входа и стадий исполнения
позиции нет. Старты, остановки и таймлайны — явно плановые значения. Сплошная линия
маршрута рисуется только когда `route_api` или `traffic_api` дали дорожную геометрию.
Аппроксимированные и «только из матрицы» плечи рисуются короткими капсулами
(`line-cap: round` на отдельных отрезках — у MapLibre квадратный `line-dasharray`),
даже если их расстояние/время взяты из дорожной матрицы. Оверлей карты красит
объекты в токены MAIN (`#272930` / `#838383` / `#FFC72C` / `#F1F1F1`; обед
`#EC6A26` / `#E2B6A5`).

`VITE_API_BASE` по умолчанию пуст: Vite проксирует `/api` на `127.0.0.1:8000`,
а Docker-образ обслуживает тот же origin через nginx → `api:8000`.

## Docker

`pnpm compose:up` запускает `web` вместе с postgres, router и api. Откройте
<http://127.0.0.1:5173>. Контейнер обращается к `api` по сети compose; отдельный
фронтовый env не нужен.

## Чего UI уже ждёт от контрактов

- SSE `plan.updated` (сейчас клиент опрашивает план после публикации)
- AI-чат диспетчера (`read-only` / `fix`) — кнопка нарочно неактивна
- эндпоинты ручного переназначения/перестановки существуют; экран переключает режим
