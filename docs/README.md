# Документация Navix

Документы ниже описывают текущую реализацию и её ограничения. Требования кейса,
согласованные решения и проектные концепции находятся в [карте контекста](../context/INDEX.md).
Версии релизов и датированные замеры сохраняются как исторические снимки;
их цифры нельзя переносить на другой набор данных или настройки без нового прогона.
