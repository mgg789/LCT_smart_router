# Бенчмарки Router Core после координат LocationIQ

> **Статус после реметрик 29.09.2026.** Этот исторический отчёт использует приближённую матрицу расстояний и `strict_time_windows=false`. Его цифры не подтверждают строгий режим или качество OSRM после исправлений.
> [Новый аудит и результаты](../routing-remetrics-20260929/README.md).

Дата: 2026-09-29. Хост: Apple M5 Pro (48 GB, macOS). OR-Tools 9.15.6755.
Суит `python -m core bench-suite` прогнан офлайн на официальных сценариях, пересобранных
из проверенного пакета `data/dataset/geocoded` (адреса LocationIQ, матрица приёмки —
гаверсинус ×1.25 при 28 км/ч, без полилиний). Предыдущий снимок на центроидных проекциях
и двух машинах остаётся в [solver-suite-20260928](../solver-suite-20260928/README.md);
его колонки Linux к этим координатам не относятся.

Ключевая конфигурация: продуктовые допуски клиентских окон (600 с), политика `compact`,
бюджет поиска 30 с, `solution_limit` 32, `strict_time_windows=false`.
Сырой отчёт: [results-m5pro-macOS.json](results-m5pro-macOS.json).
Новые runtime-настройки имеют `strict_time_windows=true`; эти цифры относятся к
указанному сценарию с допусками. Отчёт фиксирует commit `6e1ab65` и
`working_tree_dirty=true`: его входы включали незакоммиченные изменения.
Это измерение сохранённого артефакта, а не свежий замер любого последующего `dev`.

## Главные цифры

- **Восток:** Router с прогнозом выезда назначает **60 из 66 заявок (90,9%)** против 27 из 66 (40,9%) у FIFO — **+33 заявки, +122%** на тех же 12 бригадах; срочные **10 из 13 против 2 из 13**; дорога на заявку **1289 с против 2145 с (−40%)**. Это покрытие плана, не подтверждённое выполнение на линии.
- **Политика covering:** Восток **66 из 66 и все 13 срочных** (15 бригад), юго-восток 78 из 83 и 30 из 31 срочных, юго-центр **56 из 56 и все 16 срочных**.
- **Детерминизм:** три повтора Востока дали один хеш `5dd4a5a6…`, он же хеш golden-гейта `core/tests/golden/official-east-v1.json`.
- **Масштаб:** три зоны (205 заявок) — Router **142 из 205** за **5,1 с** на M5 Pro против 84 у FIFO.

На центроидной проекции продуктовый путь закрывал 62 из 66 при 1463 с дороги на заявку.
После реальных координат покрытие продуктового пути 60 из 66, дорога на заявку короче (1289 с),
потому что точки больше не сдвинуты к центру района. Статичная матрица без прогноза на Востоке
по-прежнему плотнее: 62 из 66, но считается 5,7 с вместо 0,7 с.

## 4. Воспроизведение

```bash
core/.venv/bin/python -m core bench-suite \
  --label "имя-машины" \
  --output docs/benchmarks/solver-suite-20260929/results-<host>.json
```

Суит офлайн. Колонки качества воспроизводимы; время зависит от машины. Сервер MGG в этом
прогоне не измерялся.
