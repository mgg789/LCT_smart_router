# V0.1 MVP — что выпускаем

Статус на **2026-09-18**. Код и эти заметки живут на `dest`. Тег `v0.1.0` и
слияние в `main` — после демо-записей отдельным проходом, не этим коммитом.

Публичный стенд: <https://navix.droidje.com>. Локально: `pnpm compose:up` →
<http://127.0.0.1:5173>. Клики по ТЗ: [tz-acceptance.md](./tz-acceptance.md).

## Что вошло

- Официальный датасет из репозитория: 3 региона, 205 заявок / 35 инженеров.
  Повторная кнопка «Использовать датасет из ТЗ» переносит окна и смены на
  сегодняшний горизонт, дублей не создаёт.
- Автоплан после импорта, смены политики или отключения инженера. Отдельной
  кнопки «Построить план» нет.
- Жёсткие ограничения: навык, смена + окно, транспорт *если указан* в заявке.
- Карта, таймлайн, карточка заявки. Объяснения собираются из фактов снимка
  (Факты → влияние → результат), в том числе простой инженер в той же зоне.
- Сравнение с базовой FIFO из ТЗ на вкладке «Политики». В таблице пять рабочих
  политик + FIFO. Покрывающая (`covering`) выбирается в шапке, в таблицу не
  входит: она синтезирует смены и сделала бы строки несравнимыми.
- Синтезированные `covering-*` живут только пока активна покрывающая политика.
  В compact/fast/sla/eco/FIFO и в сравнении их нет.
- Снимок дня включает смены, которые начались вчера и ещё не кончились
  (`shiftEndAt` после `planningAsOf`).
- Обеды выключены по умолчанию. SMTP и AI честно `not_configured`.
- Автономный демо-сценарий с экрана входа (18 заявок Востока) — запасной показ,
  не официальный датасет.

## Чего в V0.1 нет — нарочно

- Кнопок «срочная заявка» и «отмена заявки» в UI нет. Событие дня для проверки
  перестроения — снять инженера с линии.
- Жестов ручного перетаскивания назначений нет. Режим MANUAL переключается.
- Engineer App, Client App, LLM в расчёте, SMTP — не входят в тег.
- `packages/shared` пуст: живые типы в `apps/api` и `apps/web/src/api`.
- Юго-восток и Юго-центр на стенде — центроиды районов, не печёный OSRM.
- Презентация ЛЦТ ещё не вложена.

## Как ждать сравнение политик

Первый `GET /dispatch/policy-comparison` после публикации считает каждую
стратегию с бюджетом 8 с. UI и API ждут до 90 с. Повтор по тому же снимку
берётся из кэша. Пока идёт обычный rebuild, сравнение может ответить 503 —
повторить после появления плана.
