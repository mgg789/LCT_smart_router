# Открытые данные Москвы, погода и календарь: контекст для фич (ресерч 2026-09)

> Фича-контекст: «сервис знает о городе больше, чем Excel» — дорожные работы, перекрытия, отключения воды/электричества, погода, праздники. Все источники бесплатные. Это топливо для wow-фич: планировщик, который сам скажет «в этом доме завтра отключат воду — переносим установку».

---

## 1. Портал data.mos.ru — общий порядок работы

- [Портал](https://data.mos.ru/) — >1000 наборов; [документация API](https://data.mos.ru/developers/documentation), [песочница без ключа](https://data.mos.ru/developers/useApi).
- Формат: `https://apidata.mos.ru/v1/datasets/{id}/rows?api_key={key}&$top=...&$skip=...` (OData-подобные фильтры); ключ бесплатный по регистрации.
- Категории «Транспорт и дороги», «Энергетика», «ЖКХ» — там всё нужное. Перед демо выгрузить нужные наборы в `data/aux/` и работать офлайн.

## 2. Дорожные работы и перекрытия → умная матрица

| Источник | Что даёт |
|---|---|
| data.mos.ru, категория «Транспорт и дороги» — наборы о дорожных работах (искать «дорожные работы», «ограничение движения») | Участки работ с адресами/координатами и периодами |
| [Карта перекрытий ЕТП](https://transport.mos.ru/mostrans/closures) — интерактивная карта перекрытий: тип (ремонт/коммерческие работы), ограничения скорости, статусы | Официальная витрина; API не заявлен — использовать как справочник/скрин, данные брать с data.mos.ru |

**Фича «город знает о работах»:** сегменты матрицы, попадающие в зону работ в актуальную дату, умножаются на коэффициент 1.3–1.6; зона показывается на карте полосой; в объяснении плана появляется фактор «на пути ремонт по данным data.mos.ru (+9 мин)». Это третий честный источник «пробок» вместе с историческими коэффициентами и 2GIS (`20`).

## 3. Отключения воды и электричества → wow-фича телекома

- **Горячая вода:** набор [«График отключения горячей воды»](https://data.apicrafter.ru/tables/datamos/hotwaterschedule) (архив data.mos.ru: 72k записей, поля Address, AdmArea) — на живом портале искать «отключение горячей воды»; официальный путь проверки — [МОЭК Онлайн](https://online.moek.ru/hotwater) и [mos.ru](https://www.mos.ru/otvet-dom-i-dvor/grafik-otklucheniya-goryachei-vodi/) (API у МОЭК нет, данные стекаются на data.mos.ru).
- **Электричество:** на data.mos.ru периодически публикуются наборы по плановым отключениям электроснабжения (искать «плановые отключения», «энергетика»); у МОЭСК публичного API нет — если набор молчит, фичу отдаём как концепт.

**Почему это сильная фича для Билайна:** если в здании отключено электричество/вода, установка и настройка оборудования бессмысленны или невозможны — заявка сорвётся. Планировщик, который видит «завтра в этом доме отключение» и либо переносит визит, либо предупреждает клиента, экономит реальные выезды. В демо — показать на 2–3 адресах сценария (в fallback-датасете заведомо добавить такие адреса, если живых данных не будет — это честно оговаривается как «слои данных города»).

## 4. Погода → коэффициенты и риски

- **Open-Meteo** — [бесплатный API без ключа](https://open-meteo.com/): прогноз 7–16 дней, историческая погода с 1940 (ERA5); лимиты free: 10 000 вызовов/день, только некоммерческое ([цены/условия](https://open-meteo.com/en/pricing)) — для хакатона идеально. Пример: `https://api.open-meteo.com/v1/forecast?latitude=55.75&longitude=37.62&hourly=temperature_2m,precipitation,wind_speed_10m`.
- **Фичи:**
  1. «Дождь/снег в день X» → коэффициент времени в пути +10–20% (снег) и предупреждение о рисках наружных работ (монтаж видеонаблюдения на фасаде в дождь — сомнительная идея).
  2. Погодный фактор в объяснении плана («снегопад 14:00 — буфер увеличен на 10 мин»).
  3. Иконка погоды в шапке дня диспетчера — мелочь, добавляет «живости».
- Кэш: один вызов в день на город — лимитов не увидим никогда.

## 5. Производственный календарь РФ

- **[isdayoff.ru](https://www.isdayoff.ru/)** — API производственного календаря (рабочий/выходной/праздничный/сокращённый день, данные из официальных источников, [Python-обёртка](https://github.com/KlukvaMors/isdayoff)); альтернативы: [calendar.kuzyak.in](https://calendar.kuzyak.in/) (JSON REST), [production-calendar.ru](https://production-calendar.ru/manual).
- **Фичи:** графики инженеров со сменами по производственному календарю; «предпраздничный день — короче смена, пересчитай план»; плотность окон клиентов в праздники (люди дома → больше заявок с узкими окнами). Effort — S, добавляет реализма расписаниям.

## 6. Сводка источников и что брать

| Источник | Бесплатно? | Фича | Effort | В скоуп |
|---|---|---|---|---|
| data.mos.ru дорожные работы | да (ключ) | локальные замедления + слой на карте | S–M | **Да** (выгрузка заранее) |
| data.mos.ru/МОЭК отключения воды | да (ключ) | «дом без воды — перенос визита» | S–M | **Да** (2–3 адреса в сценарии) |
| data.mos.ru отключения электричества | если набор живой | «нет света — установка бессмысленна» | S | Roadmap/концепт |
| Open-Meteo погода | да, без ключа | коэффициенты + предупреждения | S | **Да** |
| isdayoff календарь | да | смены/праздники | S | Да (в генераторе данных) |
| transport.mos.ru карта перекрытий | нет API | справочник/скрин для питча | — | Как аргумент |

Общие правила: все наборы выгружаются заранее (офлайн-демо), каждый слой данных имеет подпись источника в UI, слои включаются фичей-флагом, чтобы в день демо не зависеть от живых порталов.
