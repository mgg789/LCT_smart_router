# Брейншторм: идеи, фишки, концепции (максимум, с фильтром)

> Назначение: полный список идей, отсортированный по категориям с оценками **wow** (эффект на жюри/пользователя), **effort** (трудоёмкость), **risk** (что может сломаться на демо). Итог — «ядро» (берём всегда) и «усилители» (по остатку времени). Стратегия: лучше 8 фич доведённых до блеска, чем 30 сырых.

Шкала: ⭐⭐⭐ — максимум, ⭐ — мало. Effort: S ≤ полдня, M ≈ день, L > день.

## Итоговый скоуп (рекомендация)

**Ядро:** A1–A8 + B1, B4, C1, D1, D2 — это полный ответ на ТЗ с нашим уровнем полировки.
**Усилители по времени (в порядке приоритета):** B2 (симуляция — лучший демо-инструмент) → B6 (риски) → B5 (жадный режим) → C7 (анализ узких мест) → B9 (LLM-ввод) → B3 → B7/B8.
**Обещаем в презентации только то, что показываем живьём.** Остальное — «roadmap» одним слайдом.

## Анти-идеи (не делать осознанно)

1. «ИИ-агент для всего» — размыто, рискованно, против нашей стратегии.
2. Мобильное приложение — время не окупится.
3. Регистрация/роли/авторизация — не про задачу.
4. Реальная интеграция с CRM Билайна — заявить как roadmap.
5. 3D-карта/глобус — красиво, но не о задаче.
6. Микросервисы — гроб для хакатонного темпа.
