# 52 · route-engine3 — универсальный движок маршрутов и гибридный расчёт

*Дата: 2026-09-28. Статус: «Проект реализации» — код и тесты в ветке
`feat/route-engine-3`, решения по форме согласованы пользователем 2026-09-28.*

## Зачем

Роутинг по дорогам отключали из-за попарных вызовов OSRM (замеры см. в
памяти команды: батч `/table` 0.06–0.09 с против 7 с попарных на 35 заявок).
route-engine3 возвращает дороги в контур как **самодостаточный юнит**
(пользовательский выбор: отдельный сервис, подгружаемые графы «доложил
папку», переиспользование в других проектах) и добавляет пешеходную
инфраструктуру, которой не было вовсе.

## Принятые решения (2026-09-28, согласованы пользователем)

1. **Пешеходный граф вендорится в репозиторий** (`graphs/foot/`, 187 МБ),
   как автомобильный МКАД-граф. Оба графа живут в
   `services/route-engine3/graphs/` — одна копия на road-api и route-engine3.
2. **Отдельный сервис**, не расширение road-api: `/route3`, `/matrix3`,
   `/metro3` — самодостаточные контракты; traffic-модель и метро
   переиспользуются копированием в юнит (дробление road-api не проводилось).
3. **Walk/bike без трафика**: плоская средняя скорость × протяжённость
   (5/15 км/ч). Никакие прогностические движки к этим профилям не применяются.
4. **Гибрид с ре-солвом** (выбор из трёх вариантов): быстрый план по
   гаверсинусам + метро → верификация выбранных рёбер `/route3` → при
   пробитии окна один повторный солв с исправленной матрицей; остаточные
   опоздания — алерты.
5. **Метро «по своим путям»**: подходы/выходы по foot-графу, перегоны по
   геометрии линий OSM (521/528 ride-рёбер); в быстрой фазе гибрида —
   подходы по геоцентрам и быстрое метро (как раньше).

## Замеры (основа решений)

Пешеходная «враньё»-калибровка: 900 пар по трём регионам против foot-графа —
реальный путь ≈ 1.36× хорды (медианы регионов 1.33–1.40) → факторы
walk/bike/transit подняты 1.25 → **1.35** (`core/geo.py`, `straight-v2`),
автомобильный остался 1.25. Скорости не тронуты. Золотые планы не затронуты
(сценарии считают по pinned-матрицам).

## Что где лежит

| Зона | Что |
|---|---|
| `services/route-engine3/` | Сервис: `graphs.py` (супервизор osrm-routed), `server.py` (контракты v3), `traffic.py` (v2, car-only), `metro.py`, `graphs/{car,foot}/`, `graph-tools/` (сборка foot-графа) |
| `core/route3.py` | Клиент + `PreparedRoute3Matrix` + верификация плана; SSRF-охрана `ROUTE3_URL` |
| `core/hybrid.py` | Гибрид fast → verify → re-solve (`ROUTER_HYBRID=1`) |
| `core/geo.py` | Калиброванные факторы прямых |
| `core/metro.py` + `data/metro/` | Геометрия перегонов из OSM |
| [docs/route3.md](../docs/route3.md) | Контракты, встраивание, алгоритмы — основной документ |

Деталь обновления этого файла: при изменении контрактов v3 правится
`docs/route3.md` тем же коммитом; сюда — только решения и замеры.
