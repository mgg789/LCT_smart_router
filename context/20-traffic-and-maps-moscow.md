# Пробки и карты для Москвы: бесплатные варианты (ресерч 2026-09)

> Фича-контекст: (а) красивая и быстрая подложка карты по Москве; (б) честный учёт пробок в ETA и (в) показ трафика пользователю. Ограничение: бесплатно/доступно без корпоративных договоров, работоспособно в РФ.

---

## 1. Главное открытие: Yandex Tiles API бесплатен

С 3 июня 2025 **Tiles API Яндекс Карт бесплатен** для коммерческого и некоммерческого использования «на постоянной основе» при соблюдении условий ([страница продукта](https://yandex.ru/maps-api/products/tiles-api), [новость](https://habr.com/ru/news/919698/), [TAdviser](https://www.tadviser.com/index.php/Product:Yandex_Maps_API)). Это растр-тайлы подложки Яндекса — лучшее для Москвы качество подписей/детализации, которое вообще можно получить бесплатно.

- Подключение: обычные XYZ-тайлы в **Leaflet/MapLibre** (`https://core-renderer-tiles.maps.yandex.net/...` — формат выдачи проверять в ЛК после регистрации ключа).
- Важно: бесплатно — **только базовый слой**; трафик/геокодер/роутинг Яндекса остаются платными (коммерческая лицензия ~195 000 ₽/год или ~8 000 ₽/мес для малого бизнеса, [тарифы](https://yandex.ru/maps-api/tariffs)).
- Обязателен ключ из личного кабинета; условия использования — прочитать при получении ключа (проверить лимиты/требование атрибуции).

## 2. Альтернативные подложки (сравнение)

| Провайдер | Цена | Качество для Москвы | Примечание |
|---|---|---|---|
| **Яндекс Tiles API** | бесплатно (ключ) | ⭐⭐⭐ лучший | Растр; кириллица, дома, дворики; ToS Яндекса |
| **CARTO Basemaps** | бесплатно ≤5 млн тайлов/мес (API-ключ) | ⭐⭐ нормальный | Стили Voyager/Positron — красиво под наш UI, [стили на GitHub](https://github.com/cartodb/basemap-styles), работают с MapLibre из коробки ([carto.com/basemaps](https://carto.com/basemaps/)) |
| **MapTiler** | free ≈100k запросов/мес + watermark | ⭐⭐ | Векторные OSM; мало для прод, ок для демо ([цены](https://www.maptiler.com/cloud/pricing/)) |
| **OSM raster** | бесплатно (usage policy) | ⭐⭐ | Публичный сервер нельзя нагружать в прод; для демо ок |
| **Self-host векторные тайлы** (protomaps/OpenMapTiles) | бесплатно после подготовки | ⭐⭐ | Полный офлайн — наш страховый вариант для сцены (см. `06` §8) |

Рекомендация: **основной слой — Яндекс Tiles (бесплатный ключ), резерв — CARTO Voyager, офлайн-страховка — self-host тайлы**. Все три под MapLibre/Leaflet через style-URL/raster source.

## 3. Пробки: что легально доступно

Сырые данные трафика (сегменты скоростей) в РФ не отдаёт никто: Яндекс запрещает вынос данных, TomTom выключил live-traffic для РФ (2022), HERE/Google недоступны. Реальные варианты:

### 3.1 2GIS Directions API — трафик в расчёте маршрута ✅
[Directions API](https://docs.2gis.com/api/navigation/directions/overview) (`/carrouting/6.0.0/global`) строит авто-маршрут **с учётом трафика**, отдаёт время в пути и геометрию; есть [Pairs Directions](https://docs.2gis.com/api/navigation/pairs/overview) (несколько пар за вызов), [Distance Matrix API](https://docs.2gis.com/api/navigation/distance-matrix/start) и даже [TSP API](https://docs.2gis.com/api/navigation/tsp/overview) (готовое решение коммивояжёра — любопытно для сравнения с нашим солвером!). Доступ: **демо-ключ бесплатно** через «Менеджер Платформы» с лимитами, дальше подписка ([начало работы](https://docs.2gis.com/api/navigation/routing/start), [тарифы-калькулятор](https://dostavili.2gis.ru/public/0326/platform-manager/)).

Применение у нас:
- **Премиум-ETA**: канал «2GIS ETA с пробками» как альтернативный провайдер матрицы/маршрута; переключатель провайдера в UI («ETA: OSRM исторический / 2GIS с пробками») — прозрачность источников данных выглядит профессионально и честно.
- Демо-ключа хватит на хакатон (лимиты проверить при создании ключа; кэшировать ответы).
- Бонус 2GIS: маршруты «до нужного входа» (у них лучшие данные входов в здания) — фича «куда подъехать/вход».

### 3.2 Yandex JS API слой пробок — только отображение, платно
`trafficControl`/actual traffic в JS API показывает пробки визуально, но JS API — коммерческая лицензия (см. §1). Старый хак с traffic.js ([Habr 2011](https://habr.com/ru/articles/86857/)) — нарушение ToS, не используем. Если хочется показать пробки легально бесплатно — только через 2GIS (расчёт) или открытые данные (3.3).

### 3.3 Открытые данные Москвы — события, влияющие на пробки
data.mos.ru и ЦОДД публикуют **дорожные работы, перекрытия, массовые мероприятия** — не скорости, но конкретные места замедления. Использовать как «слои препятствий» поверх матрицы (подробно в `22`). Это наш честный способ показать «учёт дорожной обстановки» без платного трафика.

### 3.4 Исторические коэффициенты по часам — базовый план
Матрица OSRM × коэффициент часа (пик/межпик/выходные) — уже заложено в модель (`14` §5.2, `06` §4). Это уровень точности, достаточный для демо, и полностью офлайн. Сравнение «наш исторический ETA vs 2GIS live» — готовый слайд о зрелости подхода.

## 4. Итоговая архитектура гео-данных (обновление `09` §7)

```
Подложка:   MapLibre GL ──► Yandex Tiles (free key) │ CARTO (резерв) │ self-host (офлайн)
Матрица:    OSRM /table (кэш) ──► × hourly coefficients
Live-ETA:   2GIS Directions API (демо-ключ) ──► опциональный провайдер + сравнение
События:    data.mos.ru дорожные работы/перекрытия ──► слои + локальные замедления матрицы
```

Правила: все внешние вызовы кэшируются; у каждой ETA — подпись источника («OSRM × пиковый коэффициент» / «2GIS с трафиком»); офлайн-режим деградирует до OSRM+коэффициентов и self-host тайлов.

## 5. Риски

- Условия бесплатного Tiles API могут требовать атрибуцию/запрет смешивания с другими подложками — прочитать ToS при получении ключа (пометка «проверить»).
- Демо-ключ 2GIS: лимиты и срок жизни — уточнить при создании; заранее прогреть кэш ответов для демо-датасета.
- Визуальный стиль Яндекса нельзя перекрашивать глубоко — если под наш дизайн важна стилизация, основной слой лучше CARTO/вектор, а Яндекс — переключатель «городская подложка».

## 6. Реализация v1: точность источника и прогноз на день (17.09.2026)

Router и Dashboard различают четыре уровня данных плеча:

| `travel_source` | Что известно | Как показываем |
|---|---|---|
| `approximate` | расстояние по координатам с коэффициентом дороги и скоростью транспорта | пунктирная прямая, явно приблизительно |
| `road_matrix` | дорожные расстояние/время из точной кэшированной матрицы OSRM | пунктир между точками, потому что матрица не содержит полилинию |
| `route_api` | расстояние, время и геометрия одного маршрута | реальная линия по дорогам |
| `traffic_api` | геометрия и ETA с трафиком одного provider/cache version | реальная линия по дорогам с подписью источника |

Для первичного планирования live-пробки недостаточны: они описывают момент запроса, а
маршрут нужен на весь день. Офлайн v1 умножает автомобильное время на детерминированный
коэффициент `moscow-radial-v1`: утренний пик сильнее влияет на движение к центру,
вечерний — из центра; учитываются временной пояс Москвы и средняя удалённость плеча от
центра. Источник и коэффициент попадают в результат. Статическая матрица, которой
пользуется OR-Tools во время поиска, использует диапазон `planning_as_of`; извлечённый
кандидат затем полностью пересобирается и проверяется с плановым временем выезда каждого
плеча через `quote_at`. Следующий шаг точности — departure-time matrix/time-dependent
transit callback, чтобы solver видел те же коэффициенты непосредственно во время поиска.

Ссылка на YMArchive изучена: это архив растровых изображений пробок Яндекса для Москвы
за 2013–2015 годы, а не лицензионный набор скоростей рёбер/ETA. Его нельзя напрямую
использовать как матрицу Router. Для будущей калибровки профиля по времени и направлению
лучше подходит открытый Traffic4Cast/MeTS-10, где есть временные и направленные каналы;
любая производная модель должна хранить версию выборки и проходить offline golden gate.
