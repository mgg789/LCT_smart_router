# Legacy: центроидные геокод-пакеты (до 2026-09-29)

Прежние геокод-пакеты официального датасета ТЗ: координаты — детерминированные
проекции адресов на центроиды районов с адресным джиттером, помеченные в самих
файлах как `district_centroid_projection` / «not rooftop geocoding».

**Что читать вместо них:** `data/dataset/geocoded/<region>.json` — реальные
адресные точки LocationIQ/OSM, разметка 2026-09-29; провенанс и статистика —
`data/dataset/geocoded/README.md`, инструмент — `data/tools/geocode_locationiq.py`.

**Почему хранятся:** это единственная запись того, какие координаты использовали
планы, снимки и бенчмарки, собранные до 2026-09-29. Файлы не подключаются
импортом и ни на что не ссылаются; фикс-наборы солвер-бенчмарка
(`core/scenarios/*-v1/`) — отдельный контур и продолжают жить по своим правилам
(`core/prepare_official.py`).
